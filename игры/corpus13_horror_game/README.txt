ПОСЛЕДНЯЯ СМЕНА: КОРПУС 13
===========================

Как запустить:
1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Откройте файл index.html в браузере (можно через расширение Live Server).

Файлы:
- index.html — структура игры и интерфейс.
- style.css — оформление, меню и HUD.
- game.js — игровой движок, управление, предметы, монстр и концовки.

Управление:
- W / A / S / D — движение.
- Мышь — осмотр.
- E — взаимодействие и чтение/закрытие записок.
- F — включить/выключить фонарик.
- Shift — бег.
- Esc — пауза / освобождение мыши.

Цель:
Найдите 3 предохранителя, прочитайте записку, заберите ключ-карту
и доберитесь до выхода. После нахождения всех предохранителей
появится монстр.

Примечание:
Игра работает локально в современном браузере. Для запуска не нужны
сервер, база данных или установка дополнительных библиотек.
